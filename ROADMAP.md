<h1 align="center">Roadmap</h1>

<p align="center"><a href="README.md">← Back to the README</a></p>

Next steps for Mentis. The order is not a promise of dates.

## Signed releases

- **Windows signing.** Sign `Mentis.exe`, `MentisMathText.dll` and the installer through the
  SignPath Foundation, so Windows SmartScreen no longer warns about an unknown publisher. The
  release workflow is ready; it waits for the project to be accepted.
- **macOS signing.** Sign the app with a Developer ID certificate and notarize the disk image with
  Apple, so Gatekeeper opens it without the "unidentified developer" warning. Today the macOS build
  is only ad-hoc signed.

## Website

- **Project website.** Put a Mentis website online on its own domain, with a privacy-focused host
  that complies with the GDPR and the Swiss FADP (nLPD) and holds an ISO certification, such as
  Infomaniak.
