# Settings

Open **Settings** with <kbd>Ctrl</kbd>+<kbd>,</kbd>, **Main menu** › **Settings…** or the button at the bottom left of the [Home](../getting-started/home.md): every choice applies at once, and **Defaults** resets a tab.

1. **[General](general.md)** — language, performance, guide, agents, updates
2. **[Appearance](appearance.md)** — interface font, text size, density
3. **[Editor](editor.md)** — selection, theme of new maps, writing help
4. **[Keyboard shortcuts](keyboard-shortcuts.md)** — the main keys, and how to change them
5. **[Spell check](spell-check.md)** — underline misspelled words (Windows)
