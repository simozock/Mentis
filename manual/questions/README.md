# Questions

Short answers, with a link to the page that says more.

## Mentis

**Is Mentis free?**
Yes, always: it is open source under the GNU AGPL-3.0. You can
[support it with a coffee](https://ko-fi.com/simozock).

**Does Mentis need the internet?**
No, maps stay on your computer. Only the daily update check goes online, and you can turn it off:
see [Install Mentis](../getting-started/install.md#updates).

**Does it run on an old computer?**
Yes. If it feels slow, choose the **Light** profile: see [General](../settings/general.md#performance).

**Is there a version for macOS?**
No ready package yet: build it from source with [BUILD.md](../../BUILD.md).

**Windows says "Windows protected your PC". Is it safe?**
The installer is not signed yet. Click **More info** › **Run anyway**, and download only from
[Releases](https://github.com/simozock/Mentis/releases).

## Maps and files

**Where are my maps?**
Where you saved them, one `.mentis` file each; recent ones are on the [Home](../getting-started/home.md).
See [Save and open](../files/save-and-open.md).

**I moved a picture on my computer: will the map lose it?**
No, pictures and files are copied into the map.

**Do I have to save all the time?**
No, after the first save every change saves by itself.

**Can two people work on the same map at once?**
No, a map opens in one window at a time (**File already open**). Send or export it.

**Can I open maps from other mind-map apps?**
Mentis opens `.mentis` and Markdown (`.md`) files: export Markdown there, then open it here. See
[Paste and import Markdown](../outliner/paste-and-import.md).

**How do I share a map with someone without Mentis?**
Export a [picture](../files/export-image.md), a [PDF](../files/export-pdf.md), a
[Word or Excel document](../files/export-documents.md) or [slides](../pitch/export.md).

## Editing

**Ctrl+Z does nothing. Why?**
The step may be on another sheet: the sheet list flashes and the bottom bar names it. See
[Undo and redo](../files/undo-and-redo.md).

**My topics are not where I put them.**
Switch on **Free branch positions** on the **Map** page; **Auto layout** (<kbd>Ctrl</kbd>+<kbd>L</kbd>)
tidies again. See [Arrange topics](../map/arrange.md).

**The shortcuts do not work on my Mac.**
Use <kbd>⌘</kbd> for <kbd>Ctrl</kbd> and <kbd>⌥</kbd> for <kbd>Alt</kbd>. See
[Keyboard shortcuts](../settings/keyboard-shortcuts.md).

**Is there a spell check?**
On Windows: **Settings** › **Editor**. See [Spell check](../settings/spell-check.md).

**How do I change the language?**
**Settings** › **General** › **Language**, then restart Mentis.

## Help and ideas

**I found a bug, or I have an idea.**
Write in [Issues](https://github.com/simozock/Mentis/issues/new/choose) or
[Discussions](https://github.com/simozock/Mentis/discussions).

**Can I translate Mentis?**
Yes: each language is one plain text file, editable in the browser on GitHub. See
[translations/README.md](../../translations/README.md).
